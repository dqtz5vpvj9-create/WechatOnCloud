# 打开云微后停止已有提醒

当前采用保守策略：原生客户端打开、重新显示、回到前台时，清除全部已有托盘提醒和任务栏提示；前台收到的消息也直接确认。此操作只影响云微的提醒状态，不修改微信消息或微信原生已读标记。

前端接入 `installTaskbarUnreadReset`，处理 focus、visibilitychange、pageshow 和原生 show/hide 事件；每秒校验前台状态并重试失败回执。清除时取消尚未执行的原生更新，后台快照仅保留本次打开后新接收事件对应的会话。

服务端持久化确认时间、确认标记及单调通知序号。确认后的数据库未读计数不能恢复旧提醒；晚到事件按确认序号过滤，晚同步的消息按确认时间过滤。微信消息时间精度为秒，因此确认所在秒也保守清除，优先保证旧消息不会重新闪烁。之后的新接收消息仍可提醒。

回归包括：打开后清零、前台旧快照、再次切后台后旧快照、晚到旧事件、断网回执重试、新消息重新提醒、服务重启后确认状态恢复。`tests-panel/notification-activation.e2e.ts` 覆盖 Chromium/WebKit；`tests/notification-activation.e2e.ts` 调用真实 Tauri 托盘接口。所有测试使用隔离消息，不向真实聊天发送内容。
